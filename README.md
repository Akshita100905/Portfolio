#🌐 Personal Portfolio Website

A modern and responsive **personal portfolio website** designed to showcase my skills, projects, certifications, education, and professional experience in one place.

## ✨ Features

- 👩‍💻 About Me section
- 🛠️ Skills and technologies showcase
- 📂 Projects section with project details and links
- 🎓 Education and certifications
- 📄 Resume download
- 📧 Contact section
- 🔗 Social and professional profile links
- 📱 Responsive design for desktop, tablet, and mobile devices
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactivity and dynamic functionality
